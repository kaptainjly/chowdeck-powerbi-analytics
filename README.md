# ChowDeck Power BI Analytics Dashboard

An end-to-end Power BI report analyzing ChowDeck's 2024 food delivery 
operations across Lagos, Abuja, and Port Harcourt.

## 📊 Overview
This project transforms raw operations data into an interactive 8-page 
dashboard, surfacing revenue trends, order behavior, and refund patterns 
to support business decision-making.

## 🔑 Key Insights
- **Total Revenue:** ₦371M
- **Average Order Value:** ₦11K
- **Revenue Lost to Refunds:** ₦47M

## ⚙️ Features & Techniques
- 11 custom DAX measures
- Calculated columns: Time Band, Order Size segmentation
- Custom JSON theme with ChowDeck brand colors
- Navigation bar built with locked shapes + page navigation buttons
- Synced slicers across all report pages
- Heatmap matrix for order density analysis
- Filled Map and standard Map visuals for geographic breakdown
- Top 5 Restaurants leaderboard using Top N filtering

## 📁 Files
- `ChowDeck_Dashboard.pbix` — full interactive Power BI file
- `ChowDeck_Report.pdf` — static export for quick viewing

## 🛠️ Tools
Power BI Desktop · DAX · Power Query

## 👀 How to View
Open the `.pbix` file in Power BI Desktop (free download) for the full 
interactive experience, or check the PDF for a quick overview.
